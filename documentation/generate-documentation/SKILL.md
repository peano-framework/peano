# Regenerate Doxygen Documentation

Peano's HTML API documentation is generated by Doxygen from `documentation/Doxyfile`
(see the "Documentation" section of `CLAUDE.md`). It scans `src`, `python`, `tutorials`,
`benchmarks`, `tests`, `applications`, `spack`, `docker`, `apptainer` and `documentation/`
and writes HTML to `doxygen-html/html` (gitignored). Several `.dox` files are generated
from Jupyter notebooks (`.ipynb`), so every rebuild first regenerates those.

## Steps

Run both commands from the root of the repository (or git worktree) whose
documentation you want, in this order:

1. Convert the Jupyter notebooks into `.dox` files (about 45 s):
   ```sh
   python3 documentation/convert-jupyter-notebooks.py
   ```
2. Run Doxygen (about 9 min). Run it in the background (Bash `run_in_background`)
   and wait for its completion notification:
   ```sh
   doxygen documentation/Doxyfile
   ```
3. Doxygen does not fail on warnings. Report warnings/errors about the files the
   user was just working on; the large pool of unrelated pre-existing warnings is
   expected.
4. Confirm `doxygen-html/html/index.html` was updated and tell the user.
5. Check if Firefox (or another browser) are already running and show the
   documentation. If not, invoke them on the `doxygen-html/html/index.html` file.
